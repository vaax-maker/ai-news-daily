  • 구글은 생성 AI가 대화 맥락에 맞는 UI까지 직접 생성할 수 있도록 하는 오픈 소스 프로토컬 'A2UI(Agent to User Interface)'를 공개함.
  • A2UI는 에이전트가 HTML이나 자바스크립트 같은 실행 코드를 보내는 대신, 선언적 JSON 포맷으로 UI 구성 요소와 속성, 데이터 모델을 기술하도록 설계됨.
