CLI 인증, localhost OAuth 리다이렉트 문제로 인해 SSH·컨테이너 환경에서 로그인 흐름이 …

토론
news.hada.io 2026-06-19 15:11
핵심 내용
  • CLI에서 localhost OAuth 리다이렉트를 사용할 때, SSH·컨테이너·WSL 환경에서 로그인 흐름이 멈추는 문제가 발생함
  • CLI는 노트북의 로컬 브라우저에서 빠르게 끝나는 localhost OAuth 리다이렉트를 기본값으로 사용하지만, SSH·컨테이너·WSL에서는 같은 가정이 깨져 문제가 발생함
  • 현재 방식은 CLI가 127.0.0.1에 임시 HTTP를 열고 브라우저를 인증 URL로 리다이렉트하지만, 이 과정이 개발 환경에서 제대로 작동하지 않음
  • 이로 인해 개발 환경에서 로그인 흐름이 중단되고, 사용자들이 불편을 겪음
