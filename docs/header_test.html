현재 로고 CSS:

  • height: 8rem - 로고 높이
  • transform: scaleY(0.8) - 세로 80% 축소 (납작해 보이는 원인)
  • margin-right: 0.8rem - 로고와 텍스트 간격

조정이 필요한 항목:

  • 로고 비율: transform: scaleY(0.8) 제거 또는 수정
  • 로고-텍스트 간격: margin-right 또는 gap 조정
  • 텍스트 줄간격: .slogan-container의 gap 조정
