구글 Opal 완벽 가이드: 유튜브 쇼츠 자동화 앱 만들기

출처: 그린코끼리 AI
2026년 1월 19일 12:01 PM

#GoogleOpal #AI자동화 #유튜브쇼츠 #NoCode

구글의 실험적 노코드 AI 도구인 Opal을 활용하여 유튜브 쇼츠 제작 과정을 자동화하는 핸즈온 가이드입니다. 주제 입력부터 대본, 음성, 이미지, 영상 생성까지 한 번에 처리하는 앱을 만들어봅니다.

1단계: 프로젝트 생성 및 기본 설정

STEP 1 새 프로젝트 시작

구글 Opal 사이트에 접속하여 새로운 앱 프로젝트를 생성합니다.

  • [05:38] 구글 Opal 접속 및 로그인
  • [05:50] Create 버튼 클릭
  • 앱 이름 설정 (예: 유튜브 쇼츠 자동화)

STEP 2 사용자 입력(User Input) 설정

사용자로부터 만들고 싶은 영상의 주제와 스타일을 입력받는 단계입니다.

  • [06:34] User Input 클릭 및 추가
  • 제목 변경: 주제 및 스타일 얻기
  • 입력창에 예시 질문 입력 (예: 주제와 스타일을 입력하세요)

2단계: 대본 및 음성 생성 (Core Logic)

STEP 3 쇼츠 대본 생성 (Gemini Flash)

입력받은 주제로 쇼츠 대본을 작성합니다. 속도가 빠른 Gemini Flash 모델을 사용합니다.

  • [06:51] 상단 Generate 클릭, 요소 추가
  • 제목 변경: 쇼츠대본 생성하기
  • 모델 선택: Gemini Flash
  • 프롬프트 입력:
당신은 유튜브 쇼츠 대본을 전문적으로 만드는 모델입니다. 아래 사용자 답변 정보를 기반으로 유튜브 쇼츠 전체 대본만 생성하세요. 각 장면 대본은 공백 포함 평균 50자로 4장면으로 나누고 문단을 구성하세요. 이미지 프롬프트를 만들지 마세요. 음성 스크립트 따로 분리하지 마세요. 오직 완성된 쇼츠 대본만 출력하세요. 사용자 답변: {{주제 및 스타일 얻기 결과 연결}}
  • [08:49] 이전 단계(주제 및 스타일 얻기)의 출력을 드래그하여 연결
  • [09:17] Preview로 대본 생성 테스트

STEP 4 대본 음성 변환 (AudioLM)

생성된 텍스트 대본을 AI 음성으로 변환합니다.

  • [09:48] Generate 추가
  • 제목 변경: 대본 음성 생성하기
  • 모델 선택: AudioLM (음성 생성 모델)
  • [10:29] 이전 단계(쇼츠대본 생성하기)를 드래그하여 연결

3단계: 시각 자료 생성 (Image & Video)

STEP 5 이미지 프롬프트 생성 (JSON)

대본에 맞는 이미지를 생성하기 위해, 각 장면별 프롬프트를 JSON 형식으로 생성합니다.

  • [10:36] Generate 추가 (제목: 이미지 프롬프트 생성하기)
  • 모델 선택: Gemini Flash
  • 프롬프트 입력: (JSON 형식을 요청하는 프롬프트 사용)
  • 연결: 주제 및 스타일 얻기, 쇼츠 대본 생성하기 두 가지 모두 연결

STEP 6 장면별 프롬프트 추출

생성된 전체 프롬프트 목록에서 각 장면(Scene 1~4)을 분리합니다.

  • [13:09] Generate 추가 (제목: 첫 번째 장면 이미지 프롬프트)
  • 모델: Gemini Flash
  • 프롬프트: "아래 JSON 배열에서 Scene 값이 1인 객체의 프롬프트 값만 출력해주세요."
  • 연결: 이미지 프롬프트 생성하기 결과 연결
  • [13:53] Duplicate Selection으로 4개까지 복제 후 Scene 번호(2, 3, 4)만 변경

STEP 7 이미지 생성 (Imagen/Nano)

추출된 프롬프트로 실제 이미지를 생성합니다.

  • [15:19] Generate 추가 (제목: 첫 번째 장면 이미지)
  • 모델: Imagen 3 또는 Nano (빠른 속도)
  • 연결: 첫 번째 장면 이미지 프롬프트 연결
  • 4번째 장면까지 동일하게 복제하여 연결

STEP 8 영상 생성 (Veo) - 선택 사항

정지 이미지 대신 움직이는 영상을 만들고 싶을 때 사용합니다. (예시로 1번 장면만 적용)

  • [16:50] Generate 추가 (제목: 첫 번째 장면 영상)
  • 모델 선택: Veo (영상 생성 모델)
  • 프롬프트: "이미지와 프롬프트를 이용해 영상을 생성하세요."
  • 연결 1: 첫 번째 장면 이미지 (이미지 소스)
  • 연결 2: 첫 번째 장면 이미지 프롬프트 (텍스트 소스)

4단계: 최종 결과물 구성

STEP 9 결과 페이지 레이아웃 (Output)

모든 생성물(대본, 음성, 이미지/영상)을 하나의 웹페이지 형태로 보여줍니다.

  • [18:27] 상단 Output 클릭
  • 제목 변경: 쇼츠 완성하기
  • 옵션 선택: Web Page with Auto Layout
  • 프롬프트 입력: "아래 대본과 이미 생성된 장면 이미지 또는 영상을 순서대로 매칭하여 나열해주세요."
  • 연결 작업: 장면 1~4의 이미지/영상, 쇼츠 대본, 대본 음성 모두 연결
  • [20:15] Preview 실행하여 최종 결과 확인
