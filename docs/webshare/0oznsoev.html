AI 알고리즘 기반 주식 자동매매 봇 구축 핸즈온 가이드

출처: 단테랩스 | 작성일: 2026-02-15 | 대상: OpenClaw 사용자

본 가이드는 OpenClaw를 활용하여 24시간 주식 시장을 감시하고 분석하여 자동 매매를 수행하는 AI 어시스턴트를 구축하는 과정을 다룹니다. 사용자는 구형 노트북이나 데스크톱 PC를 서버로 활용하여 시스템을 운영할 수 있습니다.

핵심 목표

크론(Cron), 하트비트(Heartbeat), 웹훅(Webhook) 기능을 결합하여 자율적으로 판단하고 실행하는 에이전트를 생성합니다. 단순히 정해진 규칙을 따르는 것이 아니라 LLM을 통해 전략을 수립하고 스스로 학습하는 구조를 지향합니다.

시스템 구축 전, 에이전트에게 명확한 페르소나를 부여해야 합니다. 이는 AI가 분석을 수행할 때 어떤 관점에서 접근할지를 결정하는 중요한 단계입니다.

실행 동작

OpenClaw 웹 UI 또는 대화창에 다음과 같은 시스템 프롬프트를 입력하여 역할을 정의하십시오.
당신은 30년 경력의 전문 주식 투자 컨설턴트입니다. 나의 자산을 관리하고 시장 데이터를 분석하여 최적의 매수/매도 전략을 제안하십시오. 말투는 정중하고 전문적이어야 하며, 데이터적 근거를 바탕으로 판단하십시오.

자동 매매를 수행하기 위해서는 증권사 API 연동 및 데이터베이스 처리를 위한 스킬(Skills)이 필요합니다. 터미널을 통해 스킬 저장소 경로로 이동하고 폴더를 생성하는 과정부터 시작합니다.

# 오픈클로 설정 폴더로 이동 cd ~/.openclaw # 스킬 폴더 생성 및 확인 mkdir skills ls -al

참고 사항

스킬은 마크다운(.md) 파일 형태로 관리되며, 상단에 Name과 Description을 포함한 프론트 메터(Front Matter) 형식을 갖춰야 에이전트가 정상적으로 인식합니다.

단테랩스에서 제공하는 전용 CLI 도구를 사용하여 키움증권 REST API 및 OpenDart 공시 정보 수집 스킬을 설치합니다. 수동 설치의 번거로움을 줄여줍니다.

# 스킬 설치 마법사 실행 npx dlabs install # 설정 단계: 1. OpenClaw 선택 2. Global Home 경로 선택 3. Trading Tools (Kiwoom, OpenDart) 선택하여 스페이스바 후 엔터

클라우드 데이터베이스인 Supabase를 연동하여 실시간 시세 및 매매 기록을 저장합니다. REST API 방식보다는 직접적인 데이터 처리를 위해 JDBC 커넥션을 활용하는 것이 효율적입니다.

설정 순서

1. Supabase에서 새 프로젝트 생성 (지역: Asia Pacific)
2. Project Settings > API에서 URL 및 Service Role Key 복사
3. OpenClaw의 Environment 변수에 아래 값을 등록
SUPABASE_URL=[본인의 URL] SUPABASE_SERVICE_ROLE_KEY=[본인의 KEY] DB_PASSWORD=[본인의 DB 암호]

국내 환경에서 리눅스 기반 자동 매매를 수행하기 위해 키움증권 REST API를 사용합니다. 이는 기존 OCX 방식과 달리 크로스 플랫폼을 지원하므로 OpenClaw 에이전트 구동에 적합합니다.

신청 및 발급

키움증권 오픈 API 페이지에서 REST API 사용 신청을 완료하십시오. 모의 투자와 실전 투자는 별도의 키 쌍(App Key, Secret Key)이 발급되므로 초기에는 모의 투자용 키를 등록하여 테스트하는 것을 권장합니다.

단순한 수치 비교를 넘어 퀀트 논문과 시장 분석 리포트를 기반으로 한 고차원 전략을 수립합니다. Liner AI의 Deep Research 기능을 사용하여 신뢰할 수 있는 출처 기반의 매매 로직을 설계합니다.

분석 포인트

1. 가격 변동성 분석
2. 수급 상관관계 데이터
3. 시계열 패턴 통합 매매 로직
위 요소들을 결합하여 통합 매수 스코어링 시스템(70점 이상 시 진입 등)을 구축합니다.

수립된 전략을 과거 데이터에 대입하여 수익률을 검증합니다. 영상의 테스트 결과 75%에 육박하는 승률을 확인하였으나, 과적합(Overfitting) 방지를 위해 지속적인 피드백 루프가 필요합니다.

크론잡(Cron) 설정 예시

- 09:30: 실시간 데이터 수집 및 스코어링 분석 수행
- 09:35: 스코어 기반 종목 선정 및 매수 실행
- 15:00: 장 마감 전 일괄 매도를 통한 수익 실현 및 청산
