구글 안티그래비티(Antigravity)로 AWS 서버 구축 및 대시보드 만들기

출처: 패스트캠퍼스  |  날짜: 2026-01-16
#GoogleAntigravity #AWS_Lightsail #AI코딩 #LAMP스택 #나노바나나

이 가이드는 구글의 AI 통합 개발 환경인 Antigravity를 사용하여 AWS Lightsail 서버를 구축하고, 코딩 없이 AI 에이전트에게 명령하여 서버 모니터링 대시보드를 배포하는 전체 과정을 다룹니다.

1. 안티그래비티 설치 및 기본 설정

다운로드 및 설치

[00:00] 구글 안티그래비티 홈페이지에서 다운로드 버튼을 눌러 설치를 진행합니다. 설치 옵션은 대부분 기본값(Default)으로 두고 진행하며, 설치 완료 후 구글 계정으로 로그인합니다.

모드 및 모델 설정

[00:59] Planning Mode(계획 모드)와 Fast Mode(빠른 실행 모드) 중 선택할 수 있습니다. 오른쪽 패널에서 사용할 AI 모델(Gemini 3, Sonnet, GPT 등)을 변경할 수 있습니다.

2. AWS Lightsail 가상 서버 생성

인스턴스 생성하기

[03:46] AWS Lightsail 콘솔에서 '인스턴스 생성'을 클릭합니다.
- 위치: 서울 (Seoul)
- 이미지: Linux/Unix 플랫폼 선택 후 'Apps + OS'에서 LAMP (PHP 8) 선택
- 네트워킹: 듀얼 스택(Dual Stack) 권장
- 요금제: 원하는 사양 선택 (예: 메모리 2GB 플랜)

고정 IP 설정

[07:23] 인스턴스가 생성되면 '네트워킹' 탭에서 '고정 IP 연결'을 선택하여 IP가 변하지 않도록 설정합니다.

3. 서버 접속 정보 준비

접속 키 및 사용자 정보 확인

[08:19] 안티그래비티가 서버에 접속하기 위해 필요한 4가지 정보를 메모장에 정리합니다.
1. IP 주소: 할당받은 고정 IP
2. 사용자 이름: bitnami (기본값)
3. 접속 키(Key): 계정 페이지에서 SSH 키(.pem)를 다운로드하고 경로 저장
4. 홈 디렉토리: 웹 파일이 위치할 경로 (보통 htdocs 폴더)

4. AI 에이전트와 서버 연결 (SSH/SCP)

작업 폴더 생성 및 연결 테스트

[12:30] PC에 'test'와 같은 빈 폴더를 만들고 안티그래비티에서 엽니다(Open Folder). 채팅창에 위에서 정리한 4가지 정보를 입력하고 "SSH 연결 테스트해줘"라고 명령합니다.

파일 배포 권한 확인

[14:42] 연결이 성공하면 "SCP로 파일 배포 가능한지 확인해줘"라고 명령하여, AI가 직접 파일을 서버에 업로드할 수 있는지 검증합니다. 초록색 체크 표시가 뜨면 준비 완료입니다.

5. 웹 대시보드 만들기 및 배포

서버 모니터링 페이지 생성

[15:41] 다음 프롬프트를 입력하여 실제 기능을 구현합니다.
"서버의 실시간 상태를 확인할 수 있는 간단한 대시보드를 만들어서 index.html로 업로드해줘."
AI가 HTML과 PHP 코드를 작성하여 서버에 자동으로 업로드합니다. 브라우저 주소창에 서버 IP를 입력하여 결과물을 확인합니다.

6. AI 이미지 생성 및 UI 개선

나노 바나나로 스플래시 이미지 생성

[19:32] 대시보드 진입 전 보여줄 '스플래시 모달(Splash Modal)' 화면을 만듭니다.
"열심히 코딩하는 펭귄과 고양이 이미지를 나노 바나나 모델로 생성해서 스플래시 화면으로 만들어줘."
생성된 이미지를 포함한 코드가 자동으로 서버에 반영됩니다.

한글 깨짐 수정 및 최종 확인

[21:37] 만약 결과 화면에서 한글이 깨져 보인다면, 깨진 화면을 캡처하여 붙여넣거나 "한글이 깨지는데 수정해줘"라고 명령하면 AI가 인코딩을 수정하여 다시 배포합니다.
