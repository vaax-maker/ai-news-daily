NotebookLM과 AntiGravity: 차세대 AI 연구 시스템 구축

출처: Jack Roberts | 작성일: 2026-01-26

0. 소개: 왜 두 도구를 결합해야 하는가?

단순한 챗봇을 넘어선 24시간 작동하는 개인용 AI 시스템을 구축하는 방법입니다. NotebookLM은 방대한 정보를 읽고 이해하는 '독자' 역할을 하며, AntiGravity는 이를 바탕으로 소프트웨어와 시스템을 설계하는 '제작자' 역할을 수행합니다.

이 조합은 대규모 파일을 읽을 때 발생하는 토큰 비용을 절감하고, 무제한에 가까운 컨텍스트를 활용할 수 있게 해줍니다.

1단계: AntiGravity 설치 및 MCP 연결

AntiGravity 내부에서 NotebookLM의 기능을 호출하기 위해서는 MCP(Model Context Protocol) 서버 연결이 필수적입니다.

Action: MCP 서버 설치하기 1. AntiGravity를 실행하고 새로운 워크스페이스 폴더를 엽니다. 2. 아래의 명령어나 프롬프트를 에이전트에게 입력하여 설정을 시작합니다.
I want to install and set up the notebook LM MCP server. Please check my system and update the MCP configuration.
Action: 브라우저 인증 - 설치 중 브라우저 창이 열리면 NotebookLM에 로그인하여 API 토큰 권한을 부여합니다.

2단계: 프로그래밍 방식으로 노트북 생성

주제를 직접 입력하여 NotebookLM에 자동으로 여러 개의 노트북을 생성하고 Deep Research 기능을 실행할 수 있습니다.

Action: 대량 지식 베이스 구축 - 에이전트에게 특정 주제(예: 유튜브 성장 전략)에 대한 5가지 하위 주제를 제안받고, 각각에 대한 노트북 생성을 요청합니다.
Create 5 different notebooks on the topics discussed using the deep research function. Ensure they gather high-quality sources from the web.

3단계: 커스텀 Skill.md 설정으로 워크플로우 자동화

AntiGravity의 'Skill' 기능을 활용하면 반복적인 지침을 매번 입력할 필요가 없습니다. 개인 비즈니스 컨텍스트를 저장하여 지능적인 답변을 유도합니다.

Action: Context 파일 생성 1. 'jack.md'와 같이 자신의 정보나 비즈니스 목표가 담긴 파일을 만듭니다. 2. 'skill.md'에 NotebookLM을 참조할 때마다 이 파일을 먼저 읽도록 지침을 추가합니다.
Whenever you reference Notebook LM, you must check the information within 'jack.md' so that the output is contextual and tailored to my business.

4단계: 인터랙티브 대시보드 및 앱 빌딩

NotebookLM의 지식을 추출하여 실제 작동하는 웹 애플리케이션을 생성합니다.

Action: HTML 대시보드 생성 - NotebookLM에서 추출한 데이터(벤치마크, 심리학적 트리거 등)를 기반으로 한 페이지짜리 인터랙티브 HTML 대시보드 제작을 요청합니다.
Build me an interactive one-pager HTML dashboard based on the information from my notebooks. Include checklists and visual metrics.

5단계: 로컬 파일(PDF) 자동 변환 및 업로드

로컬에 있는 PDF나 문서를 AntiGravity에 드롭하면, 에이전트가 이를 텍스트로 변환하여 NotebookLM에 리소스로 추가합니다.

Action: 자동 업로드 폴더 구축 1. 'notebook_to_add' 폴더를 생성합니다. 2. 파일을 해당 폴더에 넣으면 자동으로 NotebookLM에 업로드하는 파이썬 스크립트 실행을 명령합니다.
