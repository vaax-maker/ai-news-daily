Google Antigravity 마스터하기: RAPS 프레임워크로 레딧 스크래퍼 만들기

출처: Jack Roberts  |  날짜: 2026-01-16
#GoogleAntigravity #RAPS프레임워크 #AI에이전트 #MCP #Serverless

이 가이드는 Google Antigravity와 Gemini 3 모델을 활용하여 AI 앱을 빠르게 구축하는 RAPS 프레임워크(Rules, Armory, Parallel Agents, Serverless)를 실습합니다. 레딧(Reddit) 스크래퍼 앱을 만들며 에이전트 오케스트레이션과 자동화 인프라 구축 방법을 익혀보세요.

1. Rules (규칙 및 프로젝트 설정)

프로젝트 생성 및 초기 설정

[01:41] Antigravity를 실행하고 'Reddit Scraper'라는 새 폴더를 만들어 프로젝트를 시작합니다. AI에게 프로젝트의 기초가 될 제품 디자인 문서(productdesign.mmd) 작성을 요청하여 뼈대를 잡습니다.

글로벌 규칙(Global Rules) 정의

[04:09] 설정(Settings) > 커스터마이제이션(Customizations) 메뉴에서 모든 프로젝트에 적용될 '글로벌 규칙'을 설정합니다.
- Persona: 에이전트의 행동 양식 정의
- Tech Stack: 선호하는 기술 스택 지정
- Definition of Done: 작업 완료 기준 명시
이 규칙들은 에이전트의 DNA처럼 작용하여 일관된 결과물을 보장합니다.

디자인 레퍼런스 활용

[05:48] 'Design Inspo' 폴더를 생성하고 참고하고 싶은 UI 스크린샷들을 넣습니다. 에이전트에게 "이 폴더의 디자인을 참고하여 앱을 만들어줘"라고 지시하면 시각적으로 뛰어난 결과물을 얻을 수 있습니다.

2. Armory (무기고: MCP 도구 연동)

MCP(Model Context Protocol) 이해하기

[08:45] Antigravity를 단순 챗봇이 아닌 강력한 도구로 만들기 위해 외부 앱과 연결하는 MCP를 설정합니다. 주요 MCP 도구 5가지를 연결합니다: Context7, Firecrawl, Supabase, Notion, Pinecone.

Firecrawl로 웹 데이터 수집

[10:53] Firecrawl MCP를 연결하여 AI가 웹사이트를 실시간으로 탐색하고 정보를 긁어오도록 합니다. 특정 쇼핑몰 사이트에서 상품 가격을 검색하는 시연을 통해 웹 스크래핑 기능을 확인합니다.

Supabase 및 Pinecone 연동

[12:46] Supabase(데이터베이스)와 Pinecone(장기 기억/벡터 DB) MCP를 연결합니다. 이를 통해 복잡한 SQL 없이 자연어로 데이터를 저장하고, 수천 페이지의 문서를 벡터화하여 AI의 장기 기억으로 활용할 수 있습니다.

3. Parallel Agents (병렬 에이전트 오케스트레이션)

4가지 에이전트 아키타입

[20:07] 혼자 모든 것을 처리하는 대신, 역할을 분담하여 효율을 극대화합니다.
1. Design Lead: UI/UX 디자인 전담
2. Builder: 기능 구현 및 코드 작성
3. Nerd: 품질 관리(QA) 및 테스트
4. Researcher: 데이터 조사 및 전략 수립

에이전트 작업 지시 (디자인 & 기능 추가)

[20:52] Design Lead 에이전트에게 앱의 전면적인 리디자인을 지시하고, 동시에 Builder 에이전트에게는 새로운 서브레딧(예: Singularity) 스크래핑 기능을 추가하도록 지시합니다. Agent Manager Inbox에서 여러 에이전트의 작업을 동시에 관리합니다.

QA 및 감사(Audit)

[23:09] Nerd 에이전트에게 `audit.md` 워크플로우를 실행시켜 앱의 코드 품질과 기능 작동 여부를 점검하게 합니다.

4. Serverless AI Infrastructure (서버리스 자동화)

백그라운드 자동화 (Modal & Supabase)

[25:29] 로컬 환경(노트북)이 꺼져도 서비스가 돌아가도록 서버리스 인프라를 구축합니다. 예시로 1분마다 특정 웹사이트의 스크린샷을 찍어 저장하는 'Screenshot Bot'을 만듭니다.

배포 및 스케줄링

[26:14] Modal을 사용하여 코드를 클라우드에 배포하고 60초마다 실행되도록 스케줄링합니다. 결과물(스크린샷 URL)은 Supabase 데이터베이스에 자동으로 저장되도록 설정하여 완전한 무인 자동화 시스템을 완성합니다.
