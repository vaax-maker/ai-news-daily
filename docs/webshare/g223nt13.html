1. Claudebot 개요 및 주요 기능

Claudebot은 클라우드 환경이나 로컬 머신에서 매우 쉽게 설정할 수 있는 오픈소스 AI 에이전트입니다. 이 시스템의 핵심은 전체 시스템 액세스 권한을 가진다는 점이며, 다양한 스킬과 플러그인 라이브러리를 활용할 수 있습니다. [00:00:00]

주요 특징

  • 다양한 채널 연동: WhatsApp, Discord, Telegram 등 선호하는 메신저를 통해 AI와 소통할 수 있습니다.
  • 실제 활용 사례: 사용자들은 X(Twitter), Gmail, 개인 건강 데이터와 연동하여 사용하며, 특히 Meta Ray-Ban 스마트 글래스의 WhatsApp 지원을 통해 현실 세계의 정보를 처리하기도 합니다. [00:00:24]
  • 강력한 자동화: 예를 들어, 글래스로 비싼 물건을 촬영하여 Claudebot에게 보내면 아마존 가격을 비교하고 장바구니에 담는 식의 복합적인 작업이 가능합니다. [00:00:35]

2. AWS EC2를 활용한 24/7 무료 서버 구축

Claudebot을 중단 없이 구동하기 위해 AWS(Amazon Web Services)의 프리 티어를 활용하는 방법을 설명합니다. [00:00:48]

서버 설정 단계

  • 인스턴스 생성: AWS 콘솔에서 EC2 서비스를 검색한 후 'Launch Instance'를 클릭합니다. [00:00:59]
  • 사양 선택: 운영체제는 Ubuntu를 선택하며, 인스턴스 유형 검색창에 'free'를 입력하여 가장 사양이 좋은 8GB 메모리 프리 티어 인스턴스를 선택합니다. [00:01:04]
  • 서버 접속: 인스턴스 생성이 완료되면 'Connect' 버튼을 눌러 브라우저 기반의 SSH 터미널에 접속합니다. [00:02:11]

3. 한 줄 명령어를 이용한 퀵 스타트 설치

서버 터미널에 접속한 후에는 단 한 줄의 명령어로 설치를 완료할 수 있습니다. [00:02:23]

  • 설치 명령어: claw.bot 웹사이트에서 제공하는 원라이너(oneliner) 명령어를 복사하여 붙여넣습니다.
  • 설치 시간: 설정 과정 자체는 2분 이내로 매우 빠르지만, 실제 패키지 설치 및 환경 구성에는 약간의 시간이 소요될 수 있습니다. [00:02:53]

4. 초기 온보딩 및 페르소나 설정

설치가 완료되면 봇의 정체성과 동작 환경을 정의하는 온보딩 과정이 시작됩니다. [00:01:58]

설정 세부 항목

  • API 및 모델 선택: Anthropic API 키를 입력하고, 가장 지능적인 최신 모델인 Opus 4.5 등을 선택합니다. [00:02:08]
  • Hatching(부화): 봇에게 이름과 목적을 부여합니다. 영상에서는 'Jinx'라는 이름을 부여하며 제작자 AJ의 비서 역할을 하도록 설정합니다. 이 과정에서 봇의 '영혼(Soul)'과 정체성이 형성됩니다. [00:02:34]
  • 환경 설정: 타임존 설정 및 대화의 분위기(Vibe)를 선택합니다. [00:03:01]
  • 채널 페어링: 텔레그램 등의 메신저와 연결하기 위해 제공된 페어링 코드를 입력합니다. [00:03:09]

5. 스킬(Skill) 확장 및 향후 계획

Claudebot의 기능을 극대화하기 위해 MCP(Model Context Protocol) 기반의 스킬을 추가할 수 있습니다. [00:03:20]

  • Exa MCP 스킬: 고급 웹 검색 및 딥 서치 기능을 제공하는 스킬입니다. MCP를 통해 사용하면 별도의 API 키 없이 무료로 사용할 수 있다는 장점이 있습니다. [00:03:28]
  • 개발 자동화: 봇에게 자체 GitHub 계정을 부여하여 소프트웨어 개발 업무를 직접 돕게 할 수 있습니다. [00:03:48]
  • 커뮤니티 지원: Discord의 'Friends of the Crustaceans' 커뮤니티를 통해 활발한 기술 지원 및 업데이트가 이루어지고 있습니다. [00:04:21]
