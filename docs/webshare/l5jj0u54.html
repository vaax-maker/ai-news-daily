NotebookLM + AntiGravity 지식 자동화 시스템

출처: Jack Roberts (YouTube) | 최종 업데이트: 2026-01-26

0. 시스템 개요: 효율성의 극대화

단순히 정보를 저장하는 것을 넘어, AntiGravity의 실행력과 NotebookLM의 분석력을 결합하는 것이 핵심입니다. 이 시스템을 통해 수천 페이지의 문서를 단 몇 분 만에 분석하고, 이를 기반으로 실제 동작하는 코드나 전략 보고서를 생성할 수 있습니다.

기술적으로는 MCP(Model Context Protocol)를 사용하여 AI 에이전트가 외부 도구인 NotebookLM을 직접 제어하도록 설계합니다.

1. MCP 서버 및 인증 설정

에이전트가 NotebookLM에 접근하기 위해서는 전용 MCP 서버가 필요합니다. 이는 로컬 환경과 클라우드 지식 베이스를 잇는 가교 역할을 합니다.

실행 단계: 1. AntiGravity 터미널에서 MCP 설치 프롬프트를 입력합니다.
2. 팝업되는 브라우저에서 Google 계정 권한을 승인합니다. 
/install notebook-lm-mcp-server --config-update

2. Deep Research 자동화

수동으로 자료를 찾는 대신, Deep Research 기능을 호출하여 특정 주제에 대한 심층 노트북을 자동으로 생성합니다.

프롬프트 예시: "최신 AI 에이전트 트렌드에 대해 3개의 노트북을 생성하고 각각 심층 리서치를 수행해줘." 
Create 3 detailed notebooks focusing on AI Agent architectures 
using the deep research tool. Aggregate all key findings.

3. 개인화 컨텍스트 주입 (Skill.md)

AI가 내 비즈니스 상황을 이해하도록 Skill.md 파일에 개인 비즈니스 로직을 주입합니다.

핵심 설정: - 'jack.md'와 같은 프로필 파일을 생성하여 에이전트가 항상 참조하도록 강제합니다. 
# Skill Instruction
Before answering, always parse 'my_business_context.md' 
to ensure the NotebookLM data aligns with my goals.

4. 실전 앱 빌딩 및 대시보드

노트북에서 추출한 지식을 바탕으로 실제 웹 UI를 구축합니다. 단순한 텍스트 답변이 아닌 시각적 도구를 만드는 단계입니다.
