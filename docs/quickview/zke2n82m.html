1. OpenClaw의 폭발적 성장과 '로컬'의 힘

OpenClaw는 출시 직후 GitHub에서 16만 개 이상의 별(Stars)을 받으며 인터넷을 장악했습니다 [00:00:00]. 제작자 피터 슈타인베르거(Peter Steinberger)는 기존의 수많은 AI 어시스턴트들과 OpenClaw의 결정적인 차이점으로 '로컬 실행'을 꼽습니다 [01:43].

대부분의 AI 서비스가 클라우드에서 제한적인 기능만 수행하는 반면, OpenClaw는 사용자의 컴퓨터에서 직접 실행되기에 운영체제(OS)의 모든 자원에 접근할 수 있습니다. 이는 에이전트가 테슬라 자동차 제어, 집안 온도 조절, 심지어는 컴퓨터 내의 수만 개의 파일을 뒤져 사용자가 잊고 있던 1년 전의 기록까지 찾아내 서사를 만들어내는 수준의 강력한 성능을 가능케 합니다 [01:51], [02:10].

2. 앱의 시대가 저물고 '에이전트'가 지배하는 이유

피터는 향후 기존 앱의 80%가 사라질 것이라고 단언합니다 [10:43]. 그 논거는 명확합니다. 현재 우리가 사용하는 대부분의 앱은 단순한 '데이터 관리 도구'에 불과하기 때문입니다.

  • 피트니스 앱: 에이전트가 사용자의 위치 정보(식당 방문 등)와 사진을 통해 식단을 자동으로 기록하고 운동 스케줄을 조정한다면 별도의 앱에 접속해 수동으로 입력할 필요가 없습니다 [10:51].
  • To-do 앱: 단순히 "내일 이거 알려줘"라고 말하면 에이전트가 알아서 기억하고 알림을 주는데, 데이터가 어느 앱의 데이터베이스에 저장되는지는 사용자에게 중요하지 않습니다 [11:19].

결국 센서 데이터를 직접 다루는 특수 앱을 제외하고, 자연스러운 대화 인터페이스를 통해 데이터를 관리할 수 있는 에이전트가 모든 '기능'을 흡수하게 될 것입니다.

3. 봇이 인간을 고용하는 '군집 지능'의 출현

인터뷰에서는 더욱 파격적인 미래가 언급됩니다. 바로 봇과 봇 사이의 협업, 그리고 봇이 실세계의 인간을 고용하는 시나리오입니다 [03:01].

예를 들어, 식당 예약을 위해 내 에이전트가 식당측 에이전트와 협상을 벌이거나, 디지털 세계의 에이전트가 물리적인 도움이 필요할 때 인간에게 비용을 지불하고 심부름을 시키는 형태입니다. 이미 커뮤니티에서는 봇들끼리 대화하고 투표하는 Maltbook과 같은 프로젝트가 활성화되고 있습니다 [00:16].

OpenClaw의 독특한 개성은 `soul.md`라는 파일에서 기인합니다. 피터는 AI에게 단순한 지침이 아닌 '가치관'과 '성격'을 부여했습니다 [17:42]. 이 파일은 모델이 사용자와 대화할 때 훨씬 자연스럽고 때로는 '건방지거나(sassy)' 유머러스하게 반응하도록 만듭니다 [08:34].

그의 개발 방식 또한 독특합니다. 복잡한 UI 도구 대신 여러 개의 터미널 윈도우와 로컬 레포지토리 복사본을 활용하며, AI가 인간이 사용하는 CLI(명령줄 인터페이스) 도구를 직접 다루도록 교육했습니다 [18:55], [21:24]. 그는 AI를 위해 새로운 프로토콜을 만들기보다, 이미 검증된 Unix 철학의 도구들을 AI에게 쥐어주는 것이 가장 효율적이라고 믿습니다.
