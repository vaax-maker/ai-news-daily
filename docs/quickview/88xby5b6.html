1. 구글 Gemini 3.1 Pro: 종합 지능 1위 탈환

구글이 최신 모델인 Gemini 3.1 Pro를 출시하며 다시 한번 소타(SOTA) 모델의 자리에 올랐습니다 [03:14]. 가장 놀라운 변화는 벤치마크 점수의 비약적인 상승입니다. ARC-AGI-2 벤치마크에서 기존 31.1점에서 77.1점으로 약 2.5배 가량 성능이 폭발적으로 향상되었습니다 [03:53]. 이 점수는 기존 1위였던 Claude Opus 4.6(68.8%)이나 GPT-5.2(52.9%)를 상회하는 압도적인 수치입니다.

주요 특징 및 활용 사례

  • 이미지 및 SVG 생성: SVG 애니메이션 생성 능력이 탁월하여, 복잡한 벡터 애니메이션이나 CSS 디자인 코드를 높은 퀄리티로 출력합니다 [06:44].
  • 수능 만점 기록: 한국 2026학년도 수능 테스트에서 탐구 과목 포함 시 최초로 만점 수준에 도달하는 등 한국어 추론 능력이 극대화되었습니다 [07:29].
  • 멀티모달 통합: 사진 속 상황을 인식하여 해당 분위기에 맞는 음악을 작곡하거나(Lyria 3 연동), 텍스트 프롬프트 하나로 런칭 비디오용 애니메이션을 생성합니다 [13:00].
[Editor's Note] Google DeepMind의 공식 모델 카드에 따르면, Gemini 3.1 Pro는 안전성(Safety)과 톤 조절 능력이 이전 모델 대비 크게 개선되었으며, 특히 연구 수준의 물리 추론 벤치마크인 CritPt에서 차순위 모델을 5포인트 차로 따돌렸습니다. (출처: Google DeepMind)

2. Anthropic의 반격: Claude Sonnet 4.6 & 보안 혁신

Anthropic은 더욱 가볍고 강력해진 Claude Sonnet 4.6을 출시했습니다 [40:08]. Sonnet 4.6은 이전 플래그십 모델인 Opus 4.5급의 성능을 내면서도 비용은 5배 저렴하며, 특정 코딩 벤치마크(SWE-bench Verified)에서는 최상위권인 79.6%를 기록했습니다.

보안 혁명: Claude Code Security

단순 코딩을 넘어 Claude Code Security 기능을 프리뷰로 공개했습니다 [46:37]. 이 도구는 단순한 패턴 매칭 방식의 기존 보안 스캐너와 달리, 인간 보안 연구원처럼 코드의 로직과 데이터 흐름을 분석하여 취약점을 찾아내고 패치까지 제안합니다. 이 소식이 전해지자마자 사이버 보안 대장주인 CrowdStrike, Cloudflare 등의 주가가 일제히 폭락하며 시장에 큰 충격을 주었습니다 [49:16].

[Editor's Note] 실제로 Claude Opus 4.6은 오픈소스 코드베이스에서 수십 년간 발견되지 않았던 500개 이상의 취약점을 찾아내 검증을 마쳤습니다. 이는 AI가 보안의 '공격'뿐만 아니라 '방어' 측면에서도 핵심적인 역할을 하게 되었음을 시사합니다. (출처: Anthropic Blog)
