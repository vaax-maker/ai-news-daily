보리스(Boris)가 직접 공개한 효율 200% 코딩 세팅 & 사용법

"도구를 만든 사람은 그 도구를 가장 효율적으로 쓰는 법을 알고 있습니다. 보리스의 워크플로우를 벤치마킹하여 여러분의 개발 환경에 바로 적용해 보세요."
1

터미널 하나로 만족하지 마세요 (병렬 작업)

터미널에서 5개의 세션을 띄우고 번호를 매겨 작업하세요. 웹 세션까지 포함해 10개 이상을 동시에 돌리며, 출근길에는 폰으로도 작업합니다. 시스템 알림 설정 문서 →
병렬 작업으로 대기 시간을 없애세요.
2

무조건 모델 'Opus 4.5'를 쓰세요

속도보다 지능입니다. Opus 4.5는 도구 사용 능력이 뛰어나 사람의 개입을 줄여주므로, 결과적으로 전체 작업 속도가 더 빠릅니다.
덜 똑똑한 모델로 여러 번 수정하느라 시간을 낭비하지 마세요.
3

'CLAUDE.md'는 공용 지식 저장소

팀 전체가 공유하는 CLAUDE.md를 Git으로 관리하세요. Claude가 실수할 때마다 규칙을 추가하여 팀의 코딩 스타일을 학습시킵니다.
"다음번엔 이렇게 하지 마"라는 규칙을 적어두세요.
4

PR 과정에서 문서를 자동 업데이트

PR 시 Claude를 태그해 문서를 업데이트하게 하세요. Github Action 등을 통해 자동화할 수 있습니다. Compounding Engineering 플러그인 →
문서화 과정을 자동화하여 최신 상태를 유지하세요.
5

코딩 전 반드시 '계획 모드' 실행

Shift+Tab 두 번으로 계획 모드를 시작하세요. 계획이 완벽해질 때까지 AI와 대화한 후 코딩 모드로 전환합니다.
좋은 계획이 있으면 작업은 '한 번에(1-shot)' 성공합니다.
6

자주 쓰는 워크플로우는 '슬래시 커맨드'로

매일 반복하는 작업(예: commit-push-pr)은 명령어로 만들어 .claude/commands/에 저장하고 팀과 공유하세요.
프롬프트를 매번 치지 말고, 명령어로 만드세요.
7

'서브 에이전트'로 작업 전문화

코드 정리(code-simplifier), 테스트(verify-app) 등 목적에 맞는 하위 에이전트를 두어 워크플로우를 자동화하세요.
모든 것을 하나의 맥락에서 처리하지 마세요.
8

포맷팅은 '훅(Hook)'으로 자동 마무리

PostToolUse 훅을 사용해 AI가 코드를 생성한 직후 자동으로 포맷팅 툴을 돌리게 하여 CI 에러를 방지하세요.
AI 코드를 저장하기 전 자동으로 '예쁘게 정리'하세요.
9

보안 권한은 스마트하게 관리

무조건 허용 옵션보다는, 자주 쓰는 안전한 명령어를 .claude/settings.json에 등록하여 불필요한 승인 절차만 줄이세요.
보안과 편의성 사이의 균형을 유지하세요.
10

MCP로 모든 도구를 연결하세요

Slack, BigQuery, Sentry 등을 연결하여 AI가 코딩 도구를 넘어 강력한 업무 비서가 되게 하세요.
.mcp.json 설정을 팀과 공유하여 도구 활용을 극대화하세요.
