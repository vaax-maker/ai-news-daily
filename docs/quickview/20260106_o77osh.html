n8n 자동화 도구 설치 가이드: 평생 무료 vs 저렴한 클라우드

2026년 1월 6일
#n8n #자동화 #Docker #SelfHosting #Railway #Cloudflare

핵심 요약

비용 부담이 있는 n8n 클라우드 구독 대신, 셀프 호스팅(Self-hosting)을 통해 무료 또는 매우 저렴하게 n8n을 이용하는 두 가지 방법을 소개합니다. 자동화 시스템 구축 시 비용 절감과 운영 효율성을 극대화할 수 있습니다.

방법 1: 내 컴퓨터에 설치 (Local Hosting)

설치 및 실행 (Docker 활용)

  • 도구: Docker Desktop 설치 필요.
  • 설치 방법: 터미널에서 docker pull n8nio/n8n:latest 명령어로 이미지 다운로드.
  • 실행 설정:
    • 포트 지정: 5678 (기본 포트)
    • 볼륨 설정: 로컬 폴더와 컨테이너 연결 (데이터 보존용)
  • 접속: 웹브라우저에서 localhost:5678 입력.

외부 연동 해결 (Webhook 사용 시 필수)

로컬 주소(localhost)는 외부 서비스에서 접속할 수 없으므로 Cloudflare Tunnel을 사용하여 외부 접속용 URL을 생성해야 합니다.

  1. 임시 URL: Cloudflare 설치 후 cloudflared tunnel --url localhost:5678 명령어 실행.
  2. 고정 URL (추천): 도메인 구매 후 Cloudflare에 등록, 터널과 도메인을 연결하여 영구적인 주소 확보.

방법 2: 클라우드 서버 설치 (Cloud Hosting)

설치 및 실행 (Railway 활용)

  • 도구: Railway (PaaS 플랫폼).
  • 비용: 월 약 $5 (사용량에 따라 변동, 개인 용도시 저렴).
  • 설치 방법:
    • Railway 대시보드에서 n8n 템플릿 검색 및 배포.
    • n8n 메인, Worker, Postgres(DB), Redis, Webhook Processor가 자동 구성됨.
  • 장점: 24시간 가동되므로 예약된 자동화 실행에 적합하며, 별도의 로컬 PC 설정이 불필요함.

방식 비교 및 추천

구분 로컬 호스팅 (Docker) 클라우드 호스팅 (Railway)
비용 무료 저렴 (약 $5/월)
운영 환경 PC가 켜져 있을 때만 작동 24시간 상시 작동
난이도 중간 (네트워크 설정 필요) 쉬움 (템플릿 배포)
추천 대상 테스트 및 학습용 실제 업무 자동화 운영용
