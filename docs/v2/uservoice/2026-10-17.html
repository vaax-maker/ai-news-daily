내용

드라마를 만들던 사용자는 AI가 대사의 감정을 전달하고 작은 소품의 연속성을 맞추기 어렵다고 했습니다. 말투가 어색하거나 장면에 안경이 갑자기 등장하는 문제가 언급됐습니다.

해설

생성 결과를 이어 붙이는 것만으로는 인물의 말투와 장면 간 소품 일관성을 확보하기 어렵다는 피드백입니다. 제작자가 직접 대사와 편집을 손보는 부담이 남아 있습니다.

서비스ChatGPT·Codex조건LG유플러스 망 접속, Cloudflare WARP 우회
내용

방에서는 ChatGPT 사이트·앱과 Codex가 열리지 않는다는 이용자들이 있었고, KT 망은 정상이라는 말과 유플러스 복구 소식이 이어졌습니다. 복구 전 Cloudflare WARP를 설치해 우회했다는 안내도 나왔습니다.

해설

AI 서비스 자체의 장애인지 특정 통신망 문제인지 현장에서 구분해야 했던 사례입니다. 작업 중 대체 경로로 WARP가 공유됐지만, 모든 이용자에게 효과가 있었다고 단정할 수는 없습니다.

02 신뢰 우려 김효율의 AI개발단

에이전트 실패 반복으로 Argo Messenger 중단

서비스Argo Messenger조건이용자 증가 후 서비스 운영
내용

운영 공지에 따르면 이용자가 늘면서 에이전트가 답하지 않거나 이유 없이 실패한 것처럼 보이는 일이 반복됐습니다. 운영진은 서비스를 잠시 내리고 구조를 처음부터 정리한 뒤 다시 돌아오겠다고 알렸습니다.

해설

사용자 증가에 따라 반복된 실패가 쌓이자 부분 수정보다 구조 재정비를 택한 사례입니다. 에이전트 기반 서비스에서는 오류 원인을 설명하고 복구 계획을 알리는 일이 신뢰 유지에 중요합니다.

03 사용성 궁금 김효율의 AI개발단

Codex 컨텍스트 기본값과 설정 파일 주의

서비스Codex·ChatGPT 워크모델GPT-6.1 Sol조건최신 Codex 앱, 설정 파일에서 model_context_window 직접 지정 시
내용

방에서 공유된 안내는 최신 Codex 앱에서 GPT-6.1 Sol을 선택하면 50만 토큰이 기본값이며, 설정 파일에 `model_context_window`를 지정해뒀다면 해당 값이 기본값을 덮어쓸 수 있다고 설명했습니다. 50만 토큰을 쓰려면 그 설정 줄을 지우라는 방법도 안내됐습니다.

해설

기본 컨텍스트 확장이 적용되지 않을 때 모델 선택뿐 아니라 과거의 사용자 설정도 확인해야 한다는 팁입니다. 설정 파일을 직접 수정한 이용자에게 특히 유용합니다.

OpenAI 장애 때 웹과 Codex가 함께 멈춤

서비스OpenAI API·ChatGPT·Codex조건웹·Codex 앱·API 사용 중
내용

일부 참여자는 OpenAI 웹과 Codex가 모두 먹통이었고 업무가 마비됐다고 했습니다. 반면 Codex 앱은 멈추지 않았다는 이용자도 있었으며, API 응답 여부는 확인하지 못했다는 말도 나왔습니다.

해설

같은 시간대에도 제품별·이용자별로 장애 체감이 달랐습니다. 웹, 앱, API를 한 덩어리로 판단하기보다 각각 상태를 확인해야 하는 상황이 드러납니다.

02 성능 불만 코난쌤 오픈채팅방

Codex 앱의 메모리 부담과 에셋 제작 비교

서비스Codex·Grok조건Codex 앱으로 에셋·그림 제작
내용

한 사용자는 Codex 앱이 RAM을 많이 사용해 에셋이나 그림을 만들 때 외에는 잘 쓰지 않게 된다고 했습니다. 에셋 생성 속도는 Grok이 더 빠르다는 비교도 나왔습니다.

해설

모델의 출력 품질뿐 아니라 데스크톱 앱의 메모리 사용량과 생성 속도가 실제 도구 선택에 영향을 줍니다. 다만 속도 비교의 구체적인 작업 조건이나 기기 사양은 공유되지 않았습니다.
